# PROMPT: Instagram + TikTok description for a finished carousel

Write two captions in Greek for the carousel [NAME]. Use ONLY facts that are on the slides.

INSTAGRAM (long)
- Line 1 = the hook (it is the only line visible before «περισσότερα»), + 1 emoji.
- 2 lines: the problem + the «αυτό» in plain words.
- The 3 value points as 1️⃣ 2️⃣ 3️⃣ (title + one short sentence + the first step).
- Warning line with ⚠️ only if the slides have a note (fake reviews, inflated prices, ad rules...).
- Offer line: «Εμείς αναλαμβάνουμε σενάρια, βιντεοληψία, μοντάζ και διαχείριση social media: 12 βίντεο τον μήνα και δώρο ένα επαγγελματικό website με SEO & GEO.»  (confirm price/VAT before adding the price)
- 📌 «Κάνε save και στείλ' το σε κάποιον που έχει [job].»
- 📩 CTA = the same as the last slide + «Link στο bio.»
- Disclaimers when needed: «Δεν αποτελεί νομική συμβουλή.», «Έλεγξε τους κανόνες διαφήμισης του κλάδου.», «Δεν είμαστε συνεργάτες των εταιρειών που αναφέρονται.»
- 8-10 hashtags: 3 about the job (#καφετέρια), 3 marketing (#socialmediamarketing #videomarketing #marketingagency), #ελλάδα, #edyx.

TIKTOK (short)
- Hook + 1 emoji, the 3 titles as a numbered list, «Επικοινώνησε μαζί μας: edyx.gr», 5 hashtags max.

TIPS to add under the captions (short): first line is the hook; no result promises; a closing question for comments if wanted.
