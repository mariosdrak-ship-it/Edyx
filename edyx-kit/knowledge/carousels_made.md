# Carousels and posts already made (reference + good examples)

Every carousel below follows: HOOK (cover) → BRIDGE → VALUE x3 → CTA. Full copy of 12 of them is in `specs/*.json` (rebuild with the kit).
Never repeat the same job or the same hook. Check this list before proposing a topic.
